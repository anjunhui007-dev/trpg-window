# TRPG Window

PC에서 ChatGPT와 나란히 띄워 사용하는 가벼운 TRPG Companion HUD입니다.

## v0.1 목표

- ChatGPT는 GM과 실제 플레이 대화를 담당합니다.
- TRPG Window는 플레이어 상태와 등장인물 프로필을 시각적으로 보여줍니다.
- 자체 AI 채팅 엔진은 포함하지 않습니다.
- 상태는 현재 브라우저 localStorage에 저장됩니다.
- 이후 외부 동기화 계층을 붙일 수 있도록 `window.TRPGWindow.getState()` / `setState()` 인터페이스를 둡니다.

## 현재 기능

- 현재 장면 등장인물 초상화
- 등장인물/동료 수동 등록
- 플레이어 레벨, HP, SP, 현재 장소 편집
- 인물 / 장비 / 정수 / 지도 패널
- 로컬 자동 저장
- 데스크톱 우측 사이드 HUD 레이아웃
