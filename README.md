# 네모네모 로직

TRPG Windows 저장소를 흑백 노노그램 웹게임으로 전환한 첫 버전입니다.

- HTML/CSS/JavaScript만 사용, 설치 및 빌드 불필요
- 5×5 입문 퍼즐 10개 수록
- 셀 직접 터치, 색칠/X/지우개, 정답 확인, 힌트, 자동 저장
- 10×10, 15×15, 20×20, 30×30은 다음 단계에서 퍼즐 데이터와 유일해 검증 후 개방 예정

실행: index.html을 브라우저에서 열거나 GitHub Pages로 배포하세요.

참고: 현재 5×5 퍼즐의 유일해 검증은 아직 완료되지 않았습니다. 다음 단계에서 퍼즐 생성기와 검증기를 추가할 예정입니다.
